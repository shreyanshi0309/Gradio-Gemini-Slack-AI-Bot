# Gradio + Gemini AI + Slack Bot 🤖

An AI-powered Slack bot built using Python, Gradio, and Google's Gemini AI.

## 🚀 Project Overview

This project integrates Gradio, Gemini AI, and Slack to create an intelligent AI assistant capable of handling text-based conversations, mathematical queries, Python code generation, and image understanding.

## ✨ Features

- **Gradio Interface:** Interactive interface for communicating with Gemini AI.
- **Gemini AI Integration:** AI-powered responses using Google's Gemini API.
- **Slack Bot Integration:** Interact with the AI assistant directly through Slack.
- **Slack Mentions:** Responds to messages mentioning the bot.
- **Text Processing:** Handles user questions and generates responses.
- **Image Support:** Downloads images shared on Slack.
- **Image Understanding:** Uses Gemini AI to analyze uploaded images and generate detailed descriptions.

## 🛠️ Tech Stack

- Python
- Gradio
- Google Gemini API
- Slack API
- Gradio Client
